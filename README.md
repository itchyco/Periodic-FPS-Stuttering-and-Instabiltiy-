# The Problem 
Almost all brand-new gaming laptops suffer from instability and performance issues. These issues don't stem from poor specifications but rather from software that comes preinstalled on these devices.
Big brands such as ASUS, HP, and MSI all install control centers on their devices that let you use pre-baked profile values or customize your own performance marks. Almost 90% of the time, all these "performance" labeled mods cause harm rather than benefit the user, as they state.
